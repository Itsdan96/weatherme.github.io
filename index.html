📱 Install on iPhone & Android

This app is built with standalone Web-App standards so it runs full-screen on both iOS and Android without an App Store download:

🍏 iPhone / iPad (Safari):
  1. Open this file or link in Safari.
  2. Tap the Share icon at the bottom.
  3. Select "Add to Home Screen".
🤖 Android (Chrome):
  1. Open in Chrome.
  2. Tap the 3-dot menu (⋮) in the top right.
  3. Tap "Add to Home screen" or "Install app".
